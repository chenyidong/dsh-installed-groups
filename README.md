# dsh-installed-groups · 已安装插件分类视图

给 DeepSeek Harness 的插件页加一个 **「分类视图」标签页**：只列已安装、可管理的插件，自动分类、可手动调整、支持搜索与一键缩放。

## 能做什么

- **自动分类**：按包名/描述关键词表把已安装插件归入 10 个默认类（界面 / 对话 / Agent 能力 / 记忆·知识 / 浏览器·自动化 / 模型·账号 / 数据·文档 / 开发工具 / 通知 / 系统工具），中英文名都能命中；命不中的进「未分类」。
- **自带插件单独一组**：随 DSH 发布、不在 profile `node_modules` 里的官方自带包（`@deepseek-ai/` 前缀）自动归到置顶的「自带插件」组，与用户自己装的插件分开；手动指定分类仍优先。工具栏「自带插件:合并 / 分开」可一键改成按名称与简介自动分到 10 类（默认合并，偏好存浏览器）。
- **手动调整**：把插件行**拖**进任何分类，或用行内下拉换类；被手动挪过的行标「手动」徽标，点 `↺` 恢复自动跟随规则。改规则不影响手动行，没手动过的行会随规则自动重排。
- **自定义分类**：工具栏「＋ 新分类」建空组（可以先建后拖），自定义组支持改名；空组可删除。拖动**分类标题**可调整分类显示顺序。
- **搜索**：按插件名、描述、分类名实时过滤；搜索时自动展开命中分类并显示 `命中/总数`。
- **版本号**：每行插件名后面跟当前装着的版本（如 `v0.30.1`）；来源是 profile 的 `node_modules`，npm / GitHub / 本地目录装的都读得到，读不到就只显示名字。
- **一键缩放**：`△ 全部折叠 / ▽ 全部展开` 一键切换所有分类；`密度：舒适 ⇄ 紧凑` 一键切换行高密度（紧凑隐藏描述、行距减半），偏好持久保存。
- **打开详情**：点插件名或行的空白处打开官方详情页；开关、分类按钮、手动徽标各管各的，不会被误触发。
- **真实开关**：每行的开关直接代理点击官方 `Switch`（`button[role="switch"]`），与官方页永不打架；内核管理（`readOnlyReason`）或尚无可切换开关的行按官方状态禁用，并在悬停提示里显示官方给出的原因，不再摆一个莫名的死灰开关。
- **官方显示名**：行名显示官方卡片的本地化标题（`pkg.meta.title` 经 locale 解析，如 `@deepseek-ai/dsh-experimental-ralph-bundle` → 「Ralph 循环」），技术包名保留在悬停提示里、仍作归类与译文缓存的 key；搜索同时匹配显示名与技术名。
- **布局持久**：分类覆盖与顺序存在 `$DSH_HOME/dsh-installed-groups/layout.json`（真实文件，升级插件、清浏览器存储都不丢）；宿主半边未就绪时自动退回浏览器存储并在工具栏标注。
- **简介中文翻译**：每行显示插件简介，英文简介自动译成简体中文并带「译」标记（悬停可见原文）。简介统一以宿主表（`dsh.description` 优先）为显示源与译文缓存键，官方卡片 DOM 只在宿主缺这个包时兜底 —— 自带包不在 profile 就用官方卡片文本再自动补译；显示源与缓存键同源，中文译文不会再命中不了。中英混合的「英文主体 + 中文尾巴」也按英文主导判据补译，不再因「含任意中文」被免翻。译文按「插件名 + 原文」存进 `$DSH_HOME/dsh-installed-groups/translations.json`：**翻过的直接加载保存结果，不再调模型**；只有原文变了（插件升级/换简介）才重翻。工具栏「中文 / 原文」一键切换显示（偏好存浏览器），「翻译简介」可手动重翻。翻译走宿主 `llm` 服务的当前默认模型、最低推理档，不接外部 API。

## 数据与边界

- 清单与开关状态：官方 `pluginManager` Remote（`listBundles`），本视图不落任何副本。
- 版本号：宿主半边读 `<profile>/node_modules/<包名>/package.json` 的 `version`（官方卡片 DOM 里没有版本信息），只读、不缓存、不改任何包。
- 简介与译文：宿主半边额外读 `dsh.description`（优先）/`description`，`GET /installed-groups/layout` 一并返回；`POST` 同路由接收 `{items:[{name,text}]}`，用默认模型批量翻译后落盘 `translations.json`（原子写）。随包 `translations.json` 是人工校对过的中文种子：首次运行初始化状态目录，之后以状态目录为准、只补齐种子里新增的条目（插件升级带来的新译文平滑落进已有状态，不覆盖已存结果）。
- 自带插件：以 `@deepseek-ai/` 包名前缀识别官方自带/实验包，单独成组置顶；profile 里不装这个前缀，判据不会误伤用户安装的包。
- 「已安装」口径：用户安装的 profile 包 + 随 dsh 发布的可选官方实验包；不可开关的内核基线行不显示。
- 本插件不能在自己的界面里关掉自己（该行不出现开关）。

## 安装

**GitHub 直装（本仓库即发布渠道，未占 npm 包名）：**

```bash
dsh plugin --profile <你的 profile> add github:chenyidong/dsh-installed-groups#v0.1.5
```

在 DSH 里也可让 Agent 用 `plugin_manager` 的 `install_bundle`，target 填上面 `github:` 开头的规格。装完重启 DSH 生效（宿主路由需要新进程；不重启也能用，只是分类暂存浏览器）。

**本地目录安装（开发态）：**

```bash
dsh plugin --profile <你的 profile> add <本目录绝对路径>
```

## 结构

| 文件 | 作用 |
|---|---|
| `index.js` | 宿主半边：`GET/PUT/POST /installed-groups/layout` 路由 + `layout.json` / `translations.json` 读写（原子写）+ 简介翻译 |
| `client.js` | 页面半边：原位增强官方 Installed 列表，渲染分类视图与中文译文 |
| `translations.json` | 随包预置的中文译文种子（人工校对，首次运行初始化到状态目录） |
| `cordis.patch.yml` | bundle 补丁层，插入宿主行 |

插件是第三方代码：装前可自查源码并锁版本。
